# Mustacho — ChatGPT Pet

Mustacho is a custom animated ChatGPT pet based on a friendly panda mascot with a fedora, curled mustache, and brown suit.

## Included

- `mustacho-spritesheet.png` — validated v2 sprite sheet (`1536x2288`, 73 frames)
- `mustacho-contact-sheet.png` — all animation states and look directions
- `mustacho-direction-qa.png` — 16-direction look review
- `mustacho-idle.gif` — idle animation preview
- `mustacho-waving.gif` — waving animation preview

## Animation states

Idle, running left/right, waving, jumping, failed, waiting, active work, review, and 16 look directions.

Created as a custom ChatGPT Work pet.
